# Project Rules & Guidelines

- **Language & Direction**: All responses must be written in Arabic from right to left enclosed within `<div dir="rtl">`.
- **Technical Terms**: Keep English technical terms as they are without translation (e.g., `model`, `settings`, `feature`, `sidebar`, `version`, `code`, `PDF`, `Excel`, `print`, `export`, etc.).
- **File Export & Formatting (Excel / PDF / Print)**:
  - **Excel**: Set sheet direction to Right-to-Left (`rightToLeft: true`), format cells properly, use clear typography, and structure data cleanly.
  - **PDF / Print**: Ensure proper RTL text alignment, Arabic font rendering/reshaping, and clean print/page layout styles.
