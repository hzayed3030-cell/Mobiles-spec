# 📱 أداة مقارنة مواصفات الهواتف الذكية (Mobile Specification Comparison Tool)

تطبيق تفاعلي مبني باستخدام **Streamlit** يتيح لك مقارنة أي عدد من الهواتف الذكية بشكل **Dynamic** كامل، مع استعراض جدول مقارنة مفصل ومخططات بيانية، وتصدير النتائج إلى **Excel** (RTL)، و **PDF**، وطباعة فورية عبر المتصفح.

---

## 🌟 الميزات الرئيسية (Key Features)

1. **إدخال ديناميكي بالكامل (Dynamic Inputs):**
   - تحديد عدد الأجهزة من 1 إلى 10 (أو أي عدد تريده).
   - توليد حقول الإدخال تلقائياً بناءً على العدد المختار.
   - قوالب مقارنة سريعة جاهزة (Presets) لأشهر الهواتف.

2. **محرك بحث ومواصفات ذكي (Smart Specs Engine):**
   - قاعدة بيانات مدمجة موسعة لأحدث الأجهزة (Samsung S25 series, S24, iPhone 16/17 series, Xiaomi, Pixel 9, OnePlus 13, Vivo, Honor, إلخ).
   - محرك استنتاج ومطابقة ذكية للموديلات الجديدة والمدخلات الحرة.

3. **تصدير احترافي متوافق مع اللغة العربية (RTL Export):**
   - **Excel (`.xlsx`):** تفعيل `rightToLeft: true`، تنسيق متناسق للألوان، حدود الخلايا، وضبط عرض الأعمدة تلقائياً.
   - **PDF (`.pdf`):** معالجة الخطوط العربية وتشكيل النصوص مع الاتجاه الصحيح للغة العربية.
   - **الطباعة المباشرة (`Print View`):** صفحة HTML مخصصة للطباعة بنقرة واحدة متوافقة مع ورق A4.

---

## 🚀 طريقة التشغيل (How to Run)

### 1. تثبيت الحزم المطلوبة (Dependencies):
```bash
pip install streamlit pandas openpyxl reportlab arabic-reshaper python-bidi beautifulsoup4
```

### 2. تشغيل التطبيق (Run Streamlit App):
```bash
streamlit run app.py
```

أو عبر النقر المزدوج على ملف `run_app.bat`.

---

## 📁 هيكلية المشروع (Project Structure)

- `app.py`: الواجهة الرئيسية للتطبيق المبنية بـ Streamlit.
- `specs_data.py`: قاعدة بيانات المواصفات ومحرك البحث الذكي.
- `export_service.py`: خدمات تصدير ملفات Excel و PDF وقوالب الطباعة مع دعم RTL.
- `GEMINI.md`: قواعد وإرشادات المشروع.
